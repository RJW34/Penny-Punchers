# Expanded audit presentation implementation

The renderer consumes snapshots and events. It does not move actors, change hurtboxes,
extend invulnerability, decide contacts, debit credits, or advance the simulation.

## Stage assets and framing

`MARIST_STAGES.json` records original and runtime hashes for Marist Green and Marist
Gates. Source packs live in `design/after-hours-32bit/stages/`. Reference photographs
were excluded; source attribution and original generated panoramas are retained.
The panoramas are unchanged RGB images, not newly separated parallax layers. Quiet
code-drawn environmental motes and separately synthesized stage loops complement them.
All four stage definitions share canonical geometry.

`ArenaCamera.cs` fits both full cel envelopes inside x40–1240/y174–664, including
facing and jump height. An action uses its whole clip envelope to avoid camera pops
between its own phase cels. There is no Core camera clamp. Fighters, projectile
centers, contact effects, field objects and debug boxes use `WorldToScreen`.
Backdrop sampling is cosmetic and deliberately independent of collision geometry.

## Animation and state readability

`animation-timing.json` declares explicit tick holds on existing artwork.
`CelTimeline.cs` selects them from action frames; interrupted states have priority.
Combat cue ages and camera shake advance on simulation ticks, respecting freeze;
environmental ambience alone uses wall time. Presentation reset clears transient
cues and state age after replay seeks, new matches and snapshot restores.

Catalog bindings are generated by `python assets/bind_buyable_presentation.py`
after canonical data generation. The generator fails before writing if a required
move or cel is absent. It preserves existing action bindings. Feints copy the exact
source anticipation; their abort uses a distinct existing pose. Branches select
different attack keys. Held startup remains tied to Core's held action frame.

The current sheets provide key poses, not newly authored full animation sets.
Rivet/Slipstream branches, dives and air throws reuse inspected existing cels;
this is recorded in `BUYABLE_PRESENTATION_BINDINGS.json`. The generated alpha
experiment in `design/after-hours-32bit/alpha-review-2026-09-05/` was rejected:
it is RGB with painted checks, not genuine transparency. Shipped RGB chroma-key
sheets and heuristic palette selection remain known art limitations. A missing
fighter pack renders a visibly labelled development placeholder.

## Actual objects, effects and audio

Field phases and geometry come from `Simulation.Fields`: Anchor arm progress,
trigger windup, Prism contact pips and cooldown all use actual object values.
Code-drawn labels and distinct marker shapes survive reduced-flash settings.
Prism pips are remaining collisions of one object, never purchased cast stocks.
Returning/arc shots follow actual velocity. Reflected shots retain source art and
show their current owner. Destruction/interception has a dissipation cue; it does
not fabricate an actor hit or parry.

Impact positions and source fighter are captured in Core events at contact time.
Rollback Add/Confirm/Cancel changes reconcile keyed local startup cues; economic
and terminal events remain confirmed. No second confirmed-event drain is played.
Per-move impact profiles set effect weight without changing hitstop or damage.

The audio generator produces 24 original PCM files. Hit/heavy variations rotate,
and a bounded 16-voice pool prioritizes defense and terminal cues over movement.
Breath sounds are synthesized noise, not recorded human performances. Stage and
phase affect ambience volume; sound metadata validation is not a speaker test.

## Live interface

Penny Punchers is live text. Portraits preserve aspect. Barlow/OFL sources and hashes
are in `UI_FONT_SOURCES.json`. HUD health uses MaxHealth; the v2 shop prices come from current product content.
The combat HUD shows owned EX families and the purchased super READY/USED state,
a small frozen saved-bank value and pending NEXT SHOP skill credits. No combat
affordability or reserve-floor display remains. Overtime has an expiring icon and
countdown, not an earned gauge. The damage trail and stun display are distinct.
Timeout and double-result labels derive from the actual terminal reason/winner.

## Verification commands and limits

```powershell
dotnet run --project assets/presentation_checks/camera/CameraChecks.csproj -- .
dotnet build assets/presentation_checks/compile/PresentationCompile.csproj
python assets/check_audio.py
```

The pure harness exercises production camera/cel selectors, all source envelopes,
both facings, separated corners and jump heights, phase duration coverage, and
feint anticipation/abort rules when catalog data is present. The isolated compile
checks presentation source against GodotSharp without touching the game's `.godot`
output. Neither substitutes for the full game build or native visual inspection.

`UiStageCameraEvidence` drives actual legal Core inputs through the production
adapter on all stages, captures corners/jumps/contact, and checks pause retention.
The native art review renders every canonical action phase and mirror palette;
its fixtures are explicitly separate from gameplay demonstrations. Final native
screenshots, legal-input tests, full-match recordings and pacing attribution must
be bound to the final exported candidate by the release workflow.
