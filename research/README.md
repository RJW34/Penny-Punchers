# Research boundary
Sources and what each supports are recorded in sources.json. They are not dependencies on ROMs, copied game code, sprites, sounds, or move tables. This pack has no Capcom asset dependency.

Third Strike is a qualitative combat-feel reference: deliberate grounded interaction, six buttons, directional parry, input execution, confirms and expressive character kits. All numeric windows, moves, credit prices, and resource rules in data/ are original prototype proposals. Exact arcade parity is NOT asserted. Do not call a generated timing value an official frame-data fact.

This prototype intentionally removes traditional earned super/EX meter. Health, stun buildup and directional-charge input timers are not spendable combat currencies. Economy and format are new design choices, not claims about Third Strike.

The conservative Godot pin is not called the latest. Confirm versions/support at WP-000 and release using official documentation. Toolchain changes need a coherent lock/update/build/export record.
