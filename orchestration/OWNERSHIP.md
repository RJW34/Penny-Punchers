# One integrator, real specialists only
Integrator owns authority, core API, state serialization, protocol, acceptance and merge/retest. Input/feel specialist owns recognizer/movement; combat specialist owns contact/defense; economy specialist owns wallet/startup/prepare/results; content/presentation owns characters/assets/UI; network/replay specialist owns restoration/transport; QA owns independent adversarial tests. Boundaries are logical, not a claim these agents exist.

Do not concurrently edit shared FighterState/Wallet/Step order/serialization/protocol schemas. Propose changes through the integrator with version/tests. Use available agent tooling only; otherwise perform roles serially. No mass repository scan or import of unrelated personal projects. Per-package completion requires actual integration, not a specialist's prose report.

Parallel opportunities after WP-003: parry/feel and scalar-economy work. After WP-006: content/presentation and private-network work. All streams reconverge for real local/network match evidence before release.

A package can be software-complete while external device/human evidence remains pending. Its downstream software work proceeds when its implemented interfaces pass; do not turn a missing physical device into an artificial dependency deadlock. The final all-tier gate still remains unpassed until real evidence exists.
