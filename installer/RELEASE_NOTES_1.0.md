# Penny Punchers 1.0

Download **Penny-Punchers-1.0-Windows-Setup.exe** for 64-bit Windows 10/11. It includes the full game runtime and installs for your account without administrator access. Launch **Penny Punchers** from the Start menu; setup offers an optional desktop shortcut. Uninstall through Windows Settings > Apps.

The installer is unsigned, so Windows may show an unknown-publisher warning. Download from this release and use the supplied SHA-256 file to check integrity.

This release contains the supplied 32-bit graphics, both Marist stages, corrected health bars and the Buyables/shop-only economy upgrades. **Vincent** is the orange motion fighter; **Thomas** is the teal charge fighter.

The installer preserves all 188 native files from the verified game candidate. Fresh installation, all 218 payload files, both shortcuts, reinstall, a seven-round installed match, 299 installed UI checks, and uninstall are verified. Player-created files and existing settings were preserved. The installer verification archive includes exact logs, reports and screenshots.

Version 1.0 is the distribution release of that verified game, with new installer and tester documentation. Gameplay/replay identity remains unchanged. Physical-controller sessions, two physical LAN PCs and human balance/feel acceptance remain outstanding; art and pacing limitations are documented in the game and repository.

Portable Windows/Linux builds and the full prior gameplay audit corpus remain available in the [verified shop-only release](https://github.com/RJW34/Penny-Punchers/releases/tag/shop-only-v2-2026-09-05). The full codebase and installer source are included in the public repository. No project-wide open-source license has been selected; existing third-party notices remain included.

Report bugs through [GitHub Issues](https://github.com/RJW34/Penny-Punchers/issues), including version 1.0, Windows/graphics/input hardware, mode and reproduction steps. The installed TESTER_GUIDE.txt includes controls, log locations and uninstall instructions.
