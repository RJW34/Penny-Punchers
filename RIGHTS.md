The owner expressly authorizes the public Penny-Punchers source repository, the `v1.0` GitHub release and distribution of the Windows tester installer and tester builds. Earlier private-development or no-publishing instructions are superseded for this requested distribution.

No project-wide license has been selected for the original game code or artwork. Public availability does not apply an open-source license or replace third-party license terms. This file records the owner's publication authorization without choosing a license on the owner's behalf.

Third-party components retain their own licenses, included under `release_docs/licenses` and beside the bundled fonts. Marist architectural reference photographs are research references and are excluded from runtime packages. Original stage illustrations carry no claim of institutional endorsement.

Version 1.0 adds installer and onboarding packaging around the verified game candidate; it does not create a new gameplay certification. The Windows installer is unsigned because no code-signing certificate has been selected.
