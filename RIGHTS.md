# Project distribution status

This is a private development and audit repository. No open-source license has been selected for the original game code or artwork. Repository access does not itself grant public redistribution rights.

Third-party components retain their own licenses, included under `release_docs/licenses` and beside the bundled fonts. Marist architectural reference photographs are research references and are excluded from runtime packages. Original stage illustrations carry no claim of institutional endorsement.

Before making a public source or commercial distribution, the owner should record the intended license for the original material. This file does not choose a license on the owner's behalf.
