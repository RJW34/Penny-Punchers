## Architecture choice
We retain the independent C# core rather than adopting generic rigid-body character motion. A custom state machine makes action clocks, motion recognition, collision, input latency, transaction rollback and replays explicit. Godot is the shell, not a promise of Street Fighter feel. Specialized fighting engines are possible alternatives, but a late engine rewrite is not authorized solely to avoid unfinished work. Reuse a vetted low-level library only when it demonstrably meets the contract and its license/dependency is recorded.
