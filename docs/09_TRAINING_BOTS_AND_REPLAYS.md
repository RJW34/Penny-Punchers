# Practice, bots and replay are mandatory game systems
Training runs the same core, with visibly labeled training-only controls for credits, health, stun, position, dummy behavior, frame advance, slow motion and quick reset. None can leak into a competitive replay/session or network command. Display action state/frame, input history, parsed/failed commands, hit/hurt/pushboxes, advantage, combo damage, parry timing, selected super, wallet debit reason and reserve.

Required drills: normal motion both facings; charge and side-switch reset; same-tick EX chord; link versus cancel; target combo; low/high/air parry; red parry; multihit parry; jump-in anti-air; throw-tech; kara throw; quick rise/reversal; hit confirm to credit-cost super; denied insufficient-funds input; eco defense versus funded offense; rollback spend trace. Each drill has deterministic reset, visible success/failure and reproducible input recording.

Bots submit InputFrames only, never mutate health/wallet/action state. Provide passive/guard/jump/throw practice scripts plus playable conservative/adaptive bots. They may inspect allowed visible state, but default combat opponents have minimum reaction delay and no hidden input reading or frame-perfect parry every time. Isolate seedable RNG in snapshots. Debug perfect-parry dummy is training-only and explicitly labeled. Bots must make legal preparation plans, observe reserve/credits and distinguish end-of-match incentives. Bot strength does not prove human competitive balance.

Replay stores header identity (build, rules/content hash, fighters/supers, seed, assist), normalized input stream, preparation commits, confirmed settlements, periodic hashes and optional checkpoints. Playback reconstructs the same core, never video-only or animation-only imitation. Reject incompatible version/hash with explanation; no silent partial replay under different prices. Replay import bounds decompression, collection counts, strings, paths and payload sizes; never execute embedded code.

Replay controls: play/pause, speed, seek to checkpoint, frame advance, input/hitbox toggles, wallet graph and spend receipts. A seek restores world and economy together; don't preserve cash from a later playback time. Export a human-readable per-round economy summary plus compact machine-readable data. Round3 after scrubbing must match a fresh deterministic round3 replay.
