# Complete playable interface
Menus: title; local versus; versus bot; private host/join; training/drills; replays; settings/help; quit. Character select shows Thomas and Vincent, catalog and stage. The optional super is chosen and purchased in each round's shop. Product cards explain canonical price, input, purpose, tradeoff, replacement and expiry. All round equipment is optional.

Fight HUD shows two health bars, stun, score, timer, owned EX families, optional SUPER READY/USED/NONE, small static saved bank and nonspendable NEXT SHOP rewards. Unowned/exhausted/illegal-action cues explain rejection. Only the actual allowed reward amount is shown, with next-shop wording; ordinary hits and parries do not imply income. There is no combat currency meter, debit or reserve display. Spectating is out of scope.

Preparation has independent owner-controlled panels with bank, mixed slot alternatives, canonical prices, cart cost and remaining bank. Invalid edits retain the last valid visible cart; timeout commits that cart. Save, Load and Repeat revalidate current prices, bank and slot limits. Previous-round facts show revealed kit and confirmed objective counts without behavioral predictions. Online sides commit privately then reveal simultaneously. Local shared-screen drafts remain visible; the UI makes no secrecy claim. Controller-only navigation covers required screens, including remapping and rematch.

Remap per physical device and save per local profile without secretly assigning both players the same input. Hot-unplug pauses local play with a reconnect/abort dialog; remote play follows deterministic disconnect policy rather than locally freezing only one peer. Keyboard menu confirm must not leak as first-frame LP. Provide deadzone setting, SOCD display, chord macros for simultaneous PP/KK, and a visible control test page.

Reduce flashes, camera shake and screenfreeze intensity only in presentation; logic freeze/timing does not change. Colorblind-readable hit/block/parry feedback uses shape/sound, not just hue. Separate master/music/SFX volume, window/fullscreen, resolution, VSync/pacing toggle with recorded actual behavior. Show network delay/rollback frames/stall plainly. Store settings under the OS user-data directory; no hardcoded user path.

Default competition is manual directional execution, no auto-parry/auto-confirm/autoblock. Training-only assists are clearly marked in UI/replay and prohibited in default network sessions. Accessibility options that only remap simultaneous physical inputs do not change simulation; motion macros would and are not included.
