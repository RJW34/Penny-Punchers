# Complete playable interface
Menus: title; local versus; versus bot; private host/join; training/drills; replays; settings/help; quit. Character select includes original portraits or readable placeholders replaced with finished original treatment; three super descriptions include direct-credit cost and use case, never gauge length/stocks. Loadout is optional and resets at round boundaries.

Fight HUD shows two health bars, non-spendable stun indication, round points, timer, credit NUMERALS, chosen super/cost, EX affordability and equipped lease icons. No super/EX meter-shaped bar filling from attacks. Optional reserve is a small floor marker/value beside the single wallet. Wallet changes show a small reason-tagged debit; never pause the fight or obscure contact. Insufficient credit/reserve cues are subtle and rate-limited per command occurrence, not repeated every held frame. Spectating is out of scope; readable local HUD is not a spectator protocol.

Preparation has each local player's independently controlled panel, current credits, slot alternatives with input/property previews, total planned cost, after-lock credits, chosen reserve and expected win/loss next balances. Display assumptions: future balance projection assumes no additional combat spending. No false guarantee of next-round money. Online sides commit privately then reveal simultaneously. Local shared-screen selectors may expose drafts; final locked reveal still occurs together. The UI must not claim local draft secrecy on a single shared display. Controller-only navigation covers every required screen. No mouse required to change a pad binding or start rematch.

Remap per physical device and save per local profile without secretly assigning both players the same input. Hot-unplug pauses local play with a reconnect/abort dialog; remote play follows deterministic disconnect policy rather than locally freezing only one peer. Keyboard menu confirm must not leak as first-frame LP. Provide deadzone setting, SOCD display, chord macros for simultaneous PP/KK, and a visible control test page.

Reduce flashes, camera shake and screenfreeze intensity only in presentation; logic freeze/timing does not change. Colorblind-readable hit/block/parry feedback uses shape/sound, not just hue. Separate master/music/SFX volume, window/fullscreen, resolution, VSync/pacing toggle with recorded actual behavior. Show network delay/rollback frames/stall plainly. Store settings under the OS user-data directory; no hardcoded user path.

Default competition is manual directional execution, no auto-parry/auto-confirm/autoblock. Training-only assists are clearly marked in UI/replay and prohibited in default network sessions. Accessibility options that only remap simultaneous physical inputs do not change simulation; motion macros would and are not included.
