# Completion is a running verified prototype
A planning document, 98 declared moves, passing oracle tests, an empty shell, successful compile, one playable slice or a mocked network test is not end-to-end completion. Required software must be implemented, integrated, run, observed and evidenced. Continue fixing broken interactions found while integrating later packages.

Use reports/STATE.json with actual completed/current/blocked package ids, candidate ref, last commands and precise next actions. Acceptance results reference actual evidence. Agent work can run parallel only where tools truly support it; shared contracts have one owner and one integrator. Never claim background autonomous work when no executor remains running.

At context/tool/quota boundaries write reports/RESUME_PACKET.md: exact source ref/dirty changes, successful/failing commands, current defect with reproduction, artifacts, locks/owners, external blockers, next 5 executable steps and remaining requirement ids. Do not merely say “continue implementing.” Next session follows RESUME_PROMPT.md in the same directory.

Final handoff: source/build paths; actual Windows/Linux artifacts and launch instructions; mandatory requirement status by software/device/human; tested network conditions; real hardware used; known reproducible issues; owner feel checklist; evidence manifest. State precisely what was not run. An outstanding human/device gate is not an implemented feature, but also must not conceal unfinished code.

No demand for commercial polish, public services or infinite content expansion. Scope is the bounded two-character one-arena economy fighter. Conversely, do not defer the direct-credit resource, full match flow, optional shop, local play, private rollback, replays, training, bots, controls or native packages to a later roadmap.
