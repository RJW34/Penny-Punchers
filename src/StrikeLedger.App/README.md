# StrikeLedger.App — shop-only v2 application layer

The application library has no Godot dependency. `PurchasePlanning.Preview` delegates mixed-cart validation to canonical Core content; `QuotedPlan` binds stable product IDs, exact cost and content identity. Combat never checks saved bank to authorize an action.

`BotController` samples delayed public observations, owns deterministic RNG/queued command snapshots, and executes real `CommandEncoder` inputs. Purchases grant explicit rental/EX/super capabilities. Owned EX repeats after legal recovery and purchased supers require an unused permit. Scripted perfect-parry and practice feeds are restricted to training.

`TrainingSession` supports independent fighters, mixed loadouts and bank values; genuine input demonstrations and free comparisons; dummy recording/playback; complete world/dummy/evaluator checkpoints; and 21 drill evaluators. Exported practice frames include actual inputs, events, canonical hashes, capabilities and resolved contact facts. Training opportunities do not deposit competitive skill rewards.

Replay format 4 records quoted shop transactions, every normalized input, exact contact/use/reward event traces, canonical checkpoints and confirmed typed settlement receipts. Seeking reconstructs ownership, super uses, root dedupe state, bank and skills together. Legacy direct-spend recordings are explicitly refused without altering their source. Imports are bounded to 64 MiB, 120,000 commands and depth16; atomic same-directory publication preserves earlier bytes on failed writes. `RoundEconomyLedger` separates opening bank, shop purchase, saved bank, outcome grant, pending skill earnings, category/total cap, bank clipping and closing bank.

`PrivateMatchPeer` uses a versioned UDP header and compatible build/content/session/seat handshake, negotiated fighters plus host stage, reliable commit/reveal and quoted carts. Only input history crosses the combat boundary; peers independently calculate capabilities and skill rewards. The eight-tick rollback window restores complete Core snapshots. Reversible local startup/jump/dash cues have Add/Confirm/Cancel identities; money, use, contact and terminal cues are emitted only after confirmation. Settlement also requires matching peer terminal hashes. Pause uses a confirmed shared-tick barrier, paused peers keep their connection alive, leave is reliable, and rematch requires both peers.

`NetworkLab --self-test` exercises application regressions. `--scenario shop_only_v2` includes false predicted super-use/skill-reward correction and replay tamper rejection; `--scenario buyable_objects --data data/rulesets/buyables_full` covers expanded object interactions. `tools/run_network_lab.py` starts two actual socket processes and requires byte-identical final canonical state and replay alongside matching receipts. Loopback fault simulation is software evidence, not a two-physical-machine or human-feel result. Current evidence must be bound to the current build identity; pre-v2 reports remain historical.
